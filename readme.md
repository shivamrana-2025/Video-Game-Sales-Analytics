# 🎮 Video Game Sales & Analytics Pipeline

## 📌 Project Overview
An end-to-end Data Analysis and Engineering project that processes, cleans, stores, and analyzes global video game sales data using Python, SQLite, and Advanced SQL queries.

## 🛠️ Tech Stack Used
* **Python (Pandas):** For data ingestion, cleaning, and preprocessing.
* **SQLite & SQL:** For relational database storage and extracting business insights via queries.
* **Git/GitHub:** For version control and project documentation.

## 📊 Key Insights Extracted via SQL
1. **Top Publishers:** Nintendo leads the global market with over 1.7 Billion in sales, followed by Electronic Arts and Activision.
2. **Sales Trends:** Analyzed yearly game releases and total revenue trends over the decades.
